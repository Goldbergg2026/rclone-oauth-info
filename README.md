# Rclone — информация о личном подключении к Google Drive

**Назначение.** Этот репозиторий содержит две публичные информационные страницы для личного подключения программы rclone к Google Drive: [описание приложения](index.html) и [политику конфиденциальности](privacy.html). Создан 19 сентября 2026 года. Это небольшой веб-источник сведений о доступе и обработке данных, а не код самой программы rclone и не хранилище резервных копий.

**Что находится здесь.** `index.html` объясняет, зачем приложению доступ к файлам; `privacy.html` описывает данные, OAuth, передачу, хранение и отзыв доступа. Страницы не содержат форму входа и не принимают файлы или пароль Google.

**Состояние проверки.** В GitHub `main` на 27 сентября 2026 года найдены только эти две HTML-страницы; данных о текущем состоянии OAuth-разрешения, живой работе резервных копий и их восстановимости здесь нет. Для фактического состояния rclone и копий нужны соответствующие настройки и проверка на устройствах владельца.

**Связь с системой.** В [центральном реестре проектов](https://github.com/Goldbergg2026/chatgpt-system/blob/main/registry/projects.yaml) этот небольшой информационный репозиторий на дату проверки отсутствует; это не означает потерю страниц или принадлежность к чужому ACTIVE-проекту. Здесь находятся собственные страницы, а рабочие устройства и резервное копирование требуют своего проектного маршрута.

**Как использовать.** Откройте `index.html` для назначения доступа или `privacy.html` для политики. Исходную программу и её документацию смотрите на [rclone.org](https://rclone.org/). Ни токены, ни конфигурации OAuth не размещать в этом репозитории.

_Навигационная сводка по состоянию GitHub на 27.09.2026; живой статус подключения требует отдельной проверки._
